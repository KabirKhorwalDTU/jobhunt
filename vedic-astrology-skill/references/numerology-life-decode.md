## 1. Core Numerology Calculations

### Life Path Number
The Life Path is the most important number in numerology. It reveals the broad outline of life's journey.

**Calculation Method:**
1. Take the full date of birth: DD/MM/YYYY
2. Reduce each component:
   - Day: Add digits until single digit (OR keep Master Numbers 11, 22, 33)
   - Month: Add digits until single digit (OR keep Master Numbers)
   - Year: Add all four digits, reduce to single digit (OR keep Master Numbers)
3. Add the three reduced numbers
4. Reduce to single digit (OR keep Master Numbers 11, 22, 33)

**Example:** 6 November 2001
- Day: 6 (already single)
- Month: 11 (Master Number — keep as-is)
- Year: 2+0+0+1 = 3
- Total: 6 + 11 + 3 = 20 → But November as 11 is Master: 6 + 2 + 3 = 11 → MASTER NUMBER 11

**Note on Master Numbers:** When the month is 11, there are two valid calculation paths. Always check if the total forms a Master Number (11, 22, 33) before reducing further. Master Numbers carry both their double-digit vibration AND their reduced single digit (11/2, 22/4, 33/6).

## 2. Life-Path Decoder Framework

When generating a Life-Path Decoder reading, cover:

### a. Numerology Profile
- Calculate and explain Life Path Number (with Master Number significance if applicable)
- Calculate Birth Day Number and its energy
- Show how these numbers interact

### b. Vedic-Numerology Synthesis
- Map Life Path Number to its Vedic planet equivalent
- Check if this planet is strong or weak in the birth chart
- If strong: the numerological path is supported by the chart — natural flow
- If weak: there's tension — the person feels the pull of the path but struggles to walk it
- Identify confirmations and conflicts between the two systems

### c. Core Personality Architecture
- **Primary Drive:** Synthesize Lagna + Moon sign + Life Path into a single archetype
- **Shadow Pattern:** Identify the chart's weakest link + numerological challenge
- **Superpower:** Identify the chart's strongest planet + Birth Day Number combination

## 3. Soul-Purpose Guide Framework

3. **Dharmic Path:** 9th house — how purpose manifests in daily life
4. **Core Soul Mission Statement:** One-paragraph synthesis of all three layers
5. **Daily Alignment Practice:** Simple daily question or action that keeps the person on purpose

## 4. Career Destiny Framework

### Analysis Sources
- 10th house (D1 + D10 Dasamsa)
- 11th house (gains channel)
- Saturn position and Dasha (career discipline)
- Mercury position (business intelligence)
- Life Path Number (career mission)
- Lal Kitab career indicators

### Reading Structure
1. **Professional DNA:** What the chart says about the person's natural work style
2. **3 Best Career Paths:** Rank by chart alignment, with specific job titles/fields
3. **1 Path to Avoid:** The career archetype that will frustrate or harm them
4. **Career Timeline:** Map career peaks and transitions to Dasha periods
5. **Career Alignment Table:** Summary table with paths, scores, windows, key planets

### Scoring Career Paths
Rate each path 1-10 based on:
- How many positive planets support it (each strong planet = +2)
- How many challenging planets oppose it (each weak/afflicted planet = -1)
- Whether the current Dasha supports it (+2 if yes)
- Whether the Lal Kitab layer agrees (+1 if yes)
- Whether Life Path Number resonates (+1 if yes)

   - Career actions
   - Relationship guidance
   - Financial strategy
   - Health priorities
   - Spiritual/personal growth focus

For each year:
1. Calculate Personal Year Number
2. Identify active Antardasha and its lord's strength
3. Check for Lal Kitab age triggers
4. Synthesize into 4-5 bullet points covering career, relationships, money, health
5. Flag the year's dominant energy: growth, challenge, transition, or consolidation

## Integration with Vedic Calculator

When using the vedic_calculator.py output, compute numerology separately:

```python
# Numerology helper (add to vedic_calculator.py or compute manually)
def reduce_to_single(n):
    """Reduce number to single digit, keeping Master Numbers 11, 22, 33."""
    while n > 9:
        if n in (11, 22, 33):
            return n
        n = sum(int(d) for d in str(n))
    return n

def life_path(day, month, year):
    d = reduce_to_single(day)
    m = reduce_to_single(month)
    y = reduce_to_single(sum(int(x) for x in str(year)))
    total = d + m + y
    return reduce_to_single(total)

def personal_year(day, month, current_year):
    d = reduce_to_single(day)
    m = reduce_to_single(month)
    y = reduce_to_single(sum(int(x) for x in str(current_year)))
    return reduce_to_single(d + m + y)
```

Always cross-reference numerology outputs with the Vedic chart data for confirmations and tensions.
